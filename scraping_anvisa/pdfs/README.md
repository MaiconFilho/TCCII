# PDFs gerados pelo scraper

Esta pasta recebe localmente as bulas profissionais baixadas pelo scraper.

Os arquivos PDF são resultados da execução, não são versionados no Git e não
devem ser adicionados manualmente ao repositório. Preserve-os no computador ou
em um armazenamento externo adequado, especialmente quando for necessário
retomar uma coleta já registrada no PostgreSQL.

O arquivo `.gitkeep` mantém somente a estrutura desta pasta em novos clones.
